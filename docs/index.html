How AI Agents Work

An agent is not a mind that thinks all the time. It is a loop of ordinary code. The loop calls a model, runs what the model asks for, and repeats. Every advanced idea in this course is something added to that loop.

Start with chapter 0 See the course map

The one idea

  1. State: what the runtime holds
  2. Build context: choose what the model will see
  3. Call model: one stateless computation
  4. Model decides: a final answer or a requested action
  5. Runtime acts: validate, check policy, execute
  6. Update state: record the result, then repeat

Two of the six steps belong to the model. The other four are code you own. Memory, planning, subagents, skills, approvals, and durability all extend this loop. Each chapter opens with this map and shows which step it extends.

Colors mean roles

Every diagram and widget uses the same colors, always with a label.

  • Model The model: one call, context in, response out.
  • Your code The runtime: the loop, the rules, and running tools.
  • Tool Tools and the outside world.
  • State State, memory, and storage.
  • Context What the model sees in one call.
  • Human A person: user, approver, reviewer.

What you will be able to do

By the end, you should be able to ask an AI coding system for something like this:

"Build an agent with isolated subagents, durable task state, filesystem tools, human approval for dangerous actions, context compaction, and persistent project memory."

You will know what each phrase means and why you might want it. You will know the alternatives and what can go wrong. You will also know which decisions you must make yourself, even when the AI writes every line. Chapter 21 decodes that sentence term by term.

How to use this course

  • Read the parts in order. Each one builds on the loop from the parts before it.
  • Use the widgets. Step through them slowly and watch what the model can see at each step.
  • Answer the "Check yourself" questions before you open the answers.
  • Do the design checkpoint at the end of each part. You apply that part's ideas to a new agent before you see a reference design.
  • Follow Patch, the running example. It is a coding agent that gains one capability per chapter.
  • Use the 31 questions as a final self-test and the glossary when a term turns vague.

Progress, ticks, and your exercise notes are saved in this browser only. Nothing is sent anywhere.
